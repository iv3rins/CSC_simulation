### 视觉核验（Vision Bridge）

| 脚本 | 说明 |
|---|---|
| `vision-bridge.mjs` | **视觉桥**：直连 opencode-go 网关 `deepseek-v4-flash-vision-exp`，对截图做视觉核验（布局/空白/重叠/溢出/配色），替代 Ox 截图 MCP。单图 `node scripts/vision-bridge.mjs <img> ['提示词']`；批量 `--dir <目录> [--out <json>]`。输出 PASS/WARN/FAIL + issues。认证文件可通过 `OPENCODE_AUTH_FILE` 指定（未指定时使用当前用户数据目录）。详见 `AGENTS.md` §8 与 `docs/VISION-REPORT.md` |

浏览器 MCP 桥接脚本通过 `CHROME_DEVTOOLS_MCP_BIN` 指定 MCP 可执行文件；未指定时从 PATH 查找 `chrome-devtools-mcp`。这样脚本不依赖某台机器的绝对路径。
