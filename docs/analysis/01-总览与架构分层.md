# 01 · 总览与架构分层

> 依据：`README.md`、`backend/Cargo.toml`、`AGENTS.md`、源码目录结构（2026-08-23 工作树）。

## 1. 项目定位

CS2 职业选手生涯模拟器：玩家扮演一名 CS2 职业选手，从青训新秀到世界冠军，
经历训练养成、场内决策、伤病、转会、代言与退役。
**确定性模拟内核 + 事件驱动决策流**：同种子 + 同决策序列 = 完全一致的世界。

## 5. 三条铁律

1. **确定性核心 + 外部决策注入**：引擎内部唯一随机源 `Xoshiro256StarStar`
   （与 Kotlin 位级一致，可存档）；玩家意图经 `DecisionSource` 接口注入；
   **种子 + 决策日志 = 完全一致的世界**。
2. **引擎是编排壳，公式在规则层**：系统包引擎只做状态变更与编排，
   一切数值规则在 `csc-simulation/*`（纯函数、无状态）。
3. **csc-core 只接线**：装配（`Engine::load_from_standings`）/ 推进
   （`advance_month` 阶段管线）/ 存档（`snapshot`/`restore`）。

## 6. 两级决策流

```
世界级批次（每月）                    比赛级现场（每图）
训练重点 / 转会窗（每 4 月）/         场内干预（风格/暂停）/
伤病处理 / 代言邀约 / 人生事件         队友失误反应（鼓励/指责/无视）
      └──────────────┬──────────────┘
                     ▼
        DecisionRecorder（决策日志 + 事件镜像）
```

- 世界级：`WorldDecisionBatch::run`（csc-core/src/batch.rs）——伤病 tick + 转会/代言/人生决策批次；
- 比赛级：`conductor::run_lod_series`（csc-tournaments）——MatchIntervention + TeammateBlunder，
  仅顶级赛事触发；
- 2026 起训练改为**主动触发**（POST /training 排定，下月月首应用），不再进月度批次；
- FIFA 式主流程：`POST /advance-season` 一路模拟到赛季边界，赛季内由 `CareerDecisionSource`
  自动处理，不弹决策事件。

## 7. 数据流（一次完整游玩）

```
1. POST /games { seed, policy, player_name } → Engine::load_from_standings
   （128 队 / 640 真实昵称选手 / VRS 初始排名 / roles_baseline 校准）
2. plan_opening_month：物化开局月赛事（LIVE 闸门）
3. 循环：POST /advance-season（或 /advance {months}）→ advance_month 阶段管线：
   进新月+清锁 → 应用训练计划 → 跨年结算 → 排程登记 → 结算赛事 →
   月终收束 → VRS reseed → 月计数 → 化学收敛 → 世界决策批次
4. 期间：GET /view 高频轻量刷新；GET /journal?since= 增量事件；
   GET /replay 单场懒加载回放；WS 推送 decisions/step/journal
5. 生涯结束：GET /ending → CareerEndingEvaluator 评定传奇等级 + GOAT 评分
6. 存档：GET /save/gzip（20 年 ≈68MB JSON → ~1MB gzip）；POST /load/gzip 读档
```
