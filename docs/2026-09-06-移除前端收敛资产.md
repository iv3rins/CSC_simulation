# 2026-09-06 · 移除前端展示层 + 收敛根资产（架构变更记录）

> 本次变更：前后端彻底分离——仓库删除 `frontend/` 展示层，根目录 `assets/` 收敛为唯一资产源。
> 所有改动已在 git 暂存，可 `git log --all -- frontend` 找回历史任何一版前端。

---

## 一、为什么

用户判断：前端（TypeScript + Solid，73 源码文件 / 1.59 万行）已沦为冗余——
大量规则计算（默认决策镜像、转会 deadline 推导、HLTV Rating 复算、总评合成等）
本应唯一收敛在后端（Rust），前端却在各自镜像实现，造成"多事实源漂移"风险
（`docs/analysis/16` 的 P0-2/P1-1 已登记，历史上发生过 BUG）。

结论：**前端展示层从本仓库删除**，由独立展示层项目按 `docs/analysis/` 协议契约重建。
后端 Rust（16 crates / 4.66 万行）+ 根 `assets/`（后端数据源）为仓库唯一产品。
